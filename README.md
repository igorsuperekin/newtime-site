# Сайт АНО «Новое время»

Статический сайт для GitHub Pages.

## Структура
- `index.html` — главная страница
- `assets/style.css` — стили
- `assets/*.svg` — изображения и обложки
- `articles/*.html` — страницы аналитических материалов с текстом из DOCX

## Что заменить перед публикацией
1. В `index.html` заменить `указать рабочую почту` на реальный email.
2. В `index.html` заменить `указать ссылку` на Telegram или другой контакт.
3. Проверить, нужно ли публично показывать полный адрес по ЕГРЮЛ.
4. При необходимости добавить политику обработки персональных данных, если появится форма обратной связи.

## Публикация на GitHub Pages
1. Создать публичный репозиторий, например `newtime-site`.
2. Загрузить все файлы и папки из этого архива в корень репозитория.
3. Открыть Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: `main`, folder: `/root`.
6. Сохранить и дождаться публикации.

## Домен REG.RU
После публикации GitHub Pages можно подключить собственный домен. Для этого в Pages указать домен, а в DNS домена прописать записи GitHub Pages.
